# AI Grammar Checker 📝

An easy-to-use **AI Grammar Checker** built with **Python and Streamlit**.  
This application checks grammar mistakes and rewrites text in a more professional and clear way — **without using any API key**.

---

## 🚀 Features

- ✅ Grammar correction
- ✨ Professional sentence rewriting
- 🧠 Simple rule-based NLP (no ML / no API)
- 🖥️ Clean Streamlit interface
- 🔒 Works offline

---

## 🛠️ Technologies Used

- Python
- Streamlit
- language-tool-python
- NLP (rule-based)
